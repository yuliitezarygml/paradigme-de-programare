## 3. 🖥️ Как пользоваться редактором

### 1. Вкладки (Tabs):
- Нажми кнопку **`+ Filă`** на панели сверху или `Ctrl+N` (`Cmd+N` на Mac), чтобы создать новый пустой документ.
- Чтобы закрыть документ, нажми маленький крестик **`×`** прямо на вкладке или `Ctrl+W`. Если в файле были несохраненные изменения, программа вежливо спросит, сохранить ли их.
- Несохраненные файлы помечаются точкой: `Document 1.txt •`.

### 2. Форматирование текста (Стили):
1. Напиши любой текст и **выдели мышкой** слово или фразу.
2. На панели сверху нажимай кнопки:
   - **`B`** — сделать жирным (Bold)
   - **`I`** — сделать курсивом (Italic)
   - **`U`** — сделать подчеркнутым (Underline)
   - **`🎨 Culoare`** — выбрать цвет текста в палитре
   - Выпадающие списки — поменять шрифт и размер.
3. *Обрати внимание:* если выделить слово и нажать сначала `B`, а потом `I` и выбрать красный цвет — применятся **все три стиля сразу** (это требование пункта d: *«Stilurile trebuie să se suprapună»*).

### 3. Сохранение в RTF со стилями:
- Нажми меню **`Fișier` -> `Salvează ca...`** (или кнопку «Salvează» на панели).
- Введи имя с расширением `.rtf` (например: `referat.rtf`).
- Теперь все твои цвета и жирный шрифт надежно сохранены в файле!

### 4. Поиск и замена:
- Нажми кнопку **`Caută 🔍`** или комбинацию `Ctrl+F` (`Cmd+F`).
- Откроется окно:
  - Введи искомое слово.
  - Выбери направление: **Înainte (Down)** или **Înapoi (Up)**.
  - Поставь галочку `Sensibil la majuscule` (Match case), если важен регистр букв.
  - Нажимай `Găsește` (Find Next), `Înlocuiește` (Replace) или `Înlocuiește tot` (Replace All).
  - Кнопка `Evidențiază tot` подсветит все найденные слова желтым маркером!

## 4. 🧠 Объяснение ООП «на пальцах»

Преподаватель спросит: *«Как в этой лабораторной реализовано ООП?»*

1. **Инкапсуляция (Encapsulation):**
   - Класс [`EditorTab.java`](file:///Users/iulian/Documents/unic/lab2/src/EditorTab.java) скрывает внутреннее состояние вкладки: компонент `JTextPane`, ссылку на файл `currentFile`, флаг `isModified`. Доступ к ним идет только через методы `applyStyleToSelection()`, `getCurrentFile()`, `setModified()`.
   - Класс [`FileManager.java`](file:///Users/iulian/Documents/unic/lab2/src/FileManager.java) прячет технические детали работы с потоками ввода-вывода (`FileInputStream`, `FileOutputStream`, `RTFEditorKit`). Другим классам не нужно знать, как устроен формат RTF — они просто вызывают `fileManager.saveFile(file, doc)`.

2. **Разделение обязанностей (Single Responsibility):**
   - Вместо того чтобы писать гигантский класс на 2000 строк, проект разделен на логические кирпичики:
     - `TextEditor.java` — отвечает за главное окно, меню и панели кнопок.
     - `EditorTab.java` — отвечает за конкретный текст и применение стилей к нему.
     - `FindReplaceDialog.java` — отвечает только за окно поиска и замену.
     - `FileManager.java` — отвечает за сохранение на диск и чтение.

3. **Событийно-ориентированная модель и полиморфизм интерфейсов:**
   - Калькулятор и редактор реагируют на действия пользователя через интерфейсы слушателей Java:
     - `ActionListener` — нажатие кнопок и пунктов меню.
     - `DocumentListener` — отслеживание любого изменения текста (вставка, удаление), чтобы поставить точку `•` в заголовке вкладки.
     - `CaretListener` — перемещение курсора для обновления строки состояния внизу.

## 5. 📂 Разбор кода: почему всё устроено именно так

Вся папка `lab2/src/` содержит 5 понятных файлов:

```
lab2/src/
├── Main.java                 # Точка входа
├── TextEditor.java           # Главное окно: меню, тулбар, вкладки
├── EditorTab.java            # Объект одной вкладки и наложение стилей
├── FindReplaceDialog.java    # Окно поиска, замены и подсветки
└── FileManager.java          # Чтение и запись файлов RTF и TXT
```

### 1. `Main.java`
- Включает системный стиль окон (`UIManager.setLookAndFeel`), чтобы кнопки и меню выглядели как родные приложения на Mac или Windows.
- Запускает редактор: `new TextEditor().setVisible(true)`.

### 2. `EditorTab.java`
- Использует стандартный Swing-компонент `JTextPane` и его документ `StyledDocument`.
- **Главный секрет наложения стилей:**  
  Метод `doc.setCharacterAttributes(start, length, attr, false);`.  
  Последний аргумент **`false`** говорит Swing: *«Не стирай существующие стили текста, а объедини (наложи) новые атрибуты поверх старых!»*. Благодаря этому жирный шрифт не сбрасывает цвет, а курсив не сбрасывает подчеркивание.

### 3. `FileManager.java`
- Проверяет расширение файла:
  - Если файл заканчивается на `.rtf` — используется `rtfKit.write(out, doc, 0, doc.getLength())`. Это стандартный класс Java, который упаковывает форматированный текст в спецификацию Rich Text Format.
  - Если `.txt` — используется обычный `BufferedWriter` в кодировке `UTF-8`.

### 4. `FindReplaceDialog.java`
- Реализует поиск с направлением:
  - `down`: ищет методом `content.indexOf(target, startPos)` от текущего курсора до конца.
  - `up`: ищет методом `content.lastIndexOf(target, startPos)` назад к началу документа.
  - Если включен `wrap around` (зацикливание) и слово не найдено, поиск автоматически продолжается с противоположного конца документа.
- Функция «Evidențiază tot» использует `Highlighter` из Swing и красит фон всех найденных слов в мягкий желтый цвет.

### 5. `TextEditor.java`
- Хранит список вкладок `List<EditorTab> tabs` и компонент `JTabbedPane`.
- Добавляет на каждую вкладку кнопку закрытия `×`.
- Внизу отображает статусную строку: количество символов, количество строк, формат текущего файла.

## 6. 🎓 Шпаргалка для защиты

1. **Вопрос:** *Почему для текста используется `JTextPane`, а не обычный `JTextArea`?*  
   **Ответ:** Потому что обычный `JTextArea` поддерживает только однородный моноширинный текст (весь текст одного цвета и шрифта). А по условию задачи (пункт d) требуется менять шрифт, цвет, размер и стиль (**Bold**, *Italic*, <u>Underline</u>) для **отдельных подстрок**, при этом стили должны накладываться друг на друга. Для этого в Java предназначен компонент `JTextPane` со `StyledDocument`.

2. **Вопрос:** *Как сохраняются стили в файл?*  
   **Ответ:** Мы используем формат **RTF (Rich Text Format)** и стандартный класс Java `RTFEditorKit`. При сохранении в файл с расширением `.rtf` метод `rtfKit.write()` сериализует все стили оформления (цвета, шрифты, начертания) в стандартные RTF-теги. При открытии `rtfKit.read()` полностью восстанавливает форматирование.

3. **Вопрос:** *Как реализован поиск назад (вверх по тексту)?*  
   **Ответ:** Мы берем позицию курсора и вызываем метод `String.lastIndexOf(target, startPos)`. Он просматривает строку в обратном направлении — от курсора к началу текста.

4. **Вопрос:** *Как программа понимает, что файл был изменен?*  
   **Ответ:** К документу `StyledDocument` каждой вкладки подключен слушатель `DocumentListener`. При любой вставке или удалении символов вызывается метод `markAsModified()`, который добавляет точку `•` к заголовку вкладки и при закрытии вкладки предупреждает о необходимости сохранения.

## 7. 🛠️ Как добавить новую кнопку на панель инструментов (за 2 шага)

Если преподаватель попросит добавить новую кнопку на панель инструментов (например, кнопку **«ВЕРХНИЙ РЕГИСТР»** (перевод выделенного текста в заглавные буквы) или кнопку **«Очистить текст»**):

### Пример: добавляем кнопку «AA» (перевод выделенного текста в ВЕРХНИЙ РЕГИСТР)

#### Шаг 1. Добавь метод в `src/EditorTab.java`
Открой `EditorTab.java` и добавь метод:
```java
public void toUpperCase() {
    String selected = textPane.getSelectedText();
    if (selected != null && !selected.isEmpty()) {
        textPane.replaceSelection(selected.toUpperCase());
    }
}
```

#### Шаг 2. Создай кнопку в `src/TextEditor.java`
В методе `initToolBar()` найди место, где добавляются кнопки, и напиши:
```java
JButton btnUpper = new JButton("AA");
btnUpper.setToolTipText("Transformă în MAJUSCULE (ВЕРХНИЙ РЕГИСТР)");
btnUpper.addActionListener(e -> {
    EditorTab tab = getActiveTab();
    if (tab != null) {
        tab.toUpperCase();
    }
});
toolBar.add(btnUpper);
```

**Готово!** Теперь на верхней панели появится кнопка `AA`. Если выделить текст и нажать её, текст сразу переведется в `ЗАГЛАВНЫЕ БУКВЫ`. Это еще один отличный пример инкапсуляции и чистого ООП: действие с текстом лежит в `EditorTab`, а кнопка на панели лишь вызывает этот метод.
