## 2. 🎨 Файл стилей `theme.properties`

В корне папки `lab2` лежит файл **`theme.properties`**. Вы можете открыть его в любом текстовом редакторе и настроить:
* Цвет фона редактора (`editor.background`)
* Цвет текста (`editor.foreground`)
* Цвет курсора (`editor.caret.color`)
* Цвет выделения текста (`editor.selection.background`)
* Шрифт и размер по умолчанию (`editor.default.font.family`, `editor.default.font.size`)
* Цвета панели инструментов (`toolbar.background`)
* Цвета кнопок и вкладок (`button.background`, `tab.background` и др.)

💡 **Горячая перезагрузка стилей:**  
Вы можете изменить `theme.properties` прямо во время работы программы и нажать в верхнем меню:  
**`Vizualizare` ➔ `Reîncarcă tema din fișier (theme.properties)`** — редактор мгновенно применит новые цвета без перезапуска!

## 4. 🏆 Реализация всех требований методички (10 / 10 баллов)

### Пункт a: Редактирование, сохранение и открытие файлов (5 баллов)
* **Где реализовано:** `src/service/FileManager.java` и `src/TextEditor.java` (методы `openFileAction`, `saveTab`).
* **Как работает:**
  * `JFileChooser` позволяет выбрать файл на диске.
  * Если файл текстовый (`.txt`), читается через `BufferedReader` в кодировке UTF-8.
  * Если файл изменен, на заголовке вкладки появляется символ `*` (например, `Document 1 *`).
  * При попытке закрыть вкладку или выйти из программы с несохраненными изменениями, программа вежливо спрашивает, нужно ли сохранить файл.

### Пункт b: Поиск подстрок с учетом направления (1 балл)
* **Где реализовано:** `src/FindReplaceDialog.java` (метод `findNext`).
* **Как работает:**
  * В диалоге есть два радиобаттона: **«Înainte (spre final)»** (Вперед) и **«Înapoi (spre început)»** (Назад).
  * При поиске вперед используется `indexOf(target, caretPosition)`. Если до конца документа ничего не найдено, поиск автоматически продолжается с начала документа (*wrap around*).
  * При поиске назад используется `lastIndexOf(target, caretPosition - 1)`. Если перед курсором совпадений нет, поиск идет от конца документа.
  * Найденное слово автоматически выделяется в тексте (`textPane.select(start, end)`), и фокус переводится на него.

### Пункт c: Замена подстрок и «Заменить все» (1 балл)
* **Где реализовано:** `src/FindReplaceDialog.java` (методы `replaceCurrent` и `replaceAll`).
* **Как работает:**
  * Кнопка **«Înlocuiește»** проверяет текущее выделение; если оно совпадает с поисковым запросом, заменяет его на новый текст и сразу ищет следующее вхождение.
  * Кнопка **«Înlocuiește tot»** проходит по всему документу, аккуратно заменяет все найденные фрагменты и выводит сообщение с точным числом замен (например: *«Au fost efectuate 5 înlocuiri în document!»*).

### Пункт d: Стили на подстроках с наложением (1 балл)
* **Где реализовано:** `src/TextEditor.java` (методы `applyAttributeToSelection`, `toggleBold`, `toggleItalic`, `toggleUnderline`, `chooseTextColor`, `applyFontFamily`, `applyFontSize`).
* **Как работает:**
  * В панели инструментов доступны: семейство шрифта (`JComboBox`), размер шрифта, кнопки **B**, **I**, **U** и палитра цветов `JColorChooser`.
  * **Главная фишка наложения стилей:** вызывается метод:
    ```java
    textPane.getStyledDocument().setCharacterAttributes(start, length, attrs, false);
    ```
    Параметр `replace = false` указывает Swing **не удалять** предыдущие стили, а объединять (*merge*) их! То есть текст может одновременно быть и **жирным**, и *курсивным*, и <u>подчеркнутым</u>, и окрашенным в нужный цвет другим шрифтом.

### Пункт e: Работа с несколькими файлами во вкладках (1 балл)
* **Где реализовано:** `src/TextEditor.java` и `src/DocumentTab.java` через `JTabbedPane`.
* **Как работает:**
  * Пользователь может открыть сколько угодно файлов одновременно через «Filă nouă» (Ctrl+N) или «Deschide...» (Ctrl+O).
  * Каждая вкладка имеет собственный `JTextPane`, свой ассоциированный файл на диске, статус изменений и персональную кнопку закрытия `×`.
  * Переключение между вкладками мгновенно обновляет строку состояния внизу.

### Пункт f: Сохранение стилей в формате RTF (1 балл)
* **Где реализовано:** `src/service/FileManager.java` (методы `openFile` и `saveFile`).
* **Как работает:**
  * Используется стандартный класс Java `RTFEditorKit`.
  * При сохранении в `.rtf`:
    ```java
    rtfKit.write(new FileOutputStream(file), doc, 0, doc.getLength());
    ```
  * При открытии файла `.rtf`:
    ```java
    rtfKit.read(new FileInputStream(file), doc, 0);
    ```
  * Сохраняются все параметры: жирность, курсив, подчеркивание, цвета символов и размеры шрифта. Файл можно открыть в Microsoft Word, LibreOffice или WordPad, и все стили останутся на месте.

## 5. 🎓 Шпаргалка к защите перед преподавателем

**Вопрос 1: Как в коде обеспечено, что стили накладываются друг на друга (не затирая предыдущие)?**  
*Ответ:* В классе `TextEditor.java` в методе `applyAttributeToSelection` мы вызываем `doc.setCharacterAttributes(start, length, attrs, false)`. Ключевой момент — булев флаг `false` (параметр `replace`). Если бы стояло `true`, старые атрибуты были бы стерты. Со значением `false` новые атрибуты объединяются с уже установленными.

**Вопрос 2: Как устроена поддержка формата RTF без сторонних библиотек?**  
*Ответ:* В стандартном пакете Java `javax.swing.text.rtf` есть класс `RTFEditorKit`. Он умеет транслировать структуры `StyledDocument` в стандартную спецификацию разметки Rich Text Format (RTF) и обратно. Мы инкапсулировали эту работу в классе `FileManager.java`.

**Вопрос 3: Как реализовано направление поиска (вперед / назад)?**  
*Ответ:* В классе `FindReplaceDialog.java` метод `findNext` проверяет состояние радиобаттонов. Если выбрано направление «Вперед», вызывается метод `String.indexOf(target, startPos)` от конца текущего выделения. Если выбрано «Назад», вызывается `String.lastIndexOf(target, startPos)` от начала текущего выделения.

**Вопрос 4: Как инкапсулирована логика отдельной вкладки?**  
*Ответ:* Мы создали отдельный класс `DocumentTab.java`, который инкапсулирует компонент редактирования `JTextPane`, скролл-панель `JScrollPane`, привязанный файл `File currentFile`, название вкладки и флаг модификации `isModified`. Fereastra `TextEditor` оперирует списком таких объектов.

**Вопрос 5: Как работает внешний файл стилей?**  
*Ответ:* Класс `AppStyles.java` загружает ключ-значения из внешнего файла `theme.properties` с помощью стандартного `java.util.Properties`. Если файла нет или в нем ошибка, срабатывают безопасные значения по умолчанию (*fallback*). Пользователь может отредактировать файл и нажать в меню «Reîncarcă tema din fișier» для горячей перезагрузки цветов и шрифтов.
