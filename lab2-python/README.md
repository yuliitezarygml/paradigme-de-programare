## 4. 🧠 Реализация 4 основных принципов ООП

### 1. 🔹 Абстракция (Abstraction)
* Внешний интерфейс не зависит от деталей реализации:
  * Класс `FileManager` предоставляет чистый интерфейс `open_file()` и `save_file()`. Главному окну не нужно знать, какие кодировки используются и как обрабатываются ошибки ввода-вывода.
  * Класс `EditorTab` абстрагирует работу со сложным объектом `QTextCursor`. Команды меню вызывают абстрактные методы: `toggle_bold()`, `set_font_size(14)`, `get_content()`.

### 2. 🔹 Наследование (Inheritance)
* Все классы логически встроены в иерархию типов Qt:
  * `class TextEditorWindow(QMainWindow)` — расширяет функционал главного окна приложения.
  * `class EditorTab(QWidget)` — специализированный виджет одной вкладки документа.
  * `class FindReplaceDialog(QDialog)` — расширяет функционал диалогового окна.

### 3. 🔹 Полиморфизм (Polymorphism)
* В `main_window.py` команды меню и панели инструментов адресуются к свойству `current_tab`:
  ```python
  self.current_tab.toggle_bold()
  self.current_tab.get_content()
  ```
  Метод `get_content()` полиморфен: если документ форматирован, он возвращает стилизованный HTML; если это исходный код или plain text — чистый текст без тегов.
* В `FindReplaceDialog` метод `_find_next()` меняет стратегию поиска в зависимости от комбинации флагов (вперёд, назад, с учётом регистра).

### 4. 🔹 Инкапсуляция (Encapsulation)
* Внутреннее состояние скрыто за приватными атрибутами с префиксом `_`:
  * `EditorTab._file_path`, `EditorTab._is_modified`, `EditorTab._editor`.
  * Доступ снаружи осуществляется через контролируемые свойства `@property`: `file_path`, `is_modified`, `title`.
  * Прямое изменение флага `_is_modified` запрещено — он меняется автоматически сигналами текстового документа.

## 5. 🎓 Шпаргалка к защите перед преподавателем

**Вопрос 1: Как сохраняются стили форматирования текста (пункт f)?**  
*Ответ:* Компонент `QTextEdit` хранит форматированный документ со всеми стилями шрифтов, цветов и начертаний. Метод `EditorTab.get_content()` сериализует стили в стандартный Rich HTML, который можно открыть в любом браузере или Word, а метод `set_content()` восстанавливает форматирование при чтении.

**Вопрос 2: Как реализовано наложение стилей (например, одновременно жирный и курсив)?**  
*Ответ:* В методе `_merge_format_on_selection()` используется `cursor.mergeCharFormat(fmt)`. В отличие от перезаписи стиля (`setCharFormat`), объединение (`merge`) сохраняет уже применённые свойства (шрифт, цвет) и добавляет к ним новое начертание.

**Вопрос 3: Как предотвращается потеря данных при закрытии вкладки или программы?**  
*Ответ:* Метод `close_tab()` проверяет свойство `is_modified`. Если файл был изменён, открывается диалоговое окно `QMessageBox.question` с предложением сохранить изменения, отменить закрытие или сбросить. Метод `closeEvent()` главного окна аналогично опрашивает все вкладки перед выходом.
