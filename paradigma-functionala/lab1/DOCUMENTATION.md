## 0. Что такое функциональное программирование (в двух словах)

Представь кухонный рецепт: «положи продукты → получи блюдо». Функция в функциональном
стиле работает так же: **получила данные → вернула результат**, и всё. Она:

1. **Ничего не портит.** Список, который ей дали, остаётся прежним. Если нужен другой
   список, функция собирает **новый**.
2. **Всегда даёт один ответ на одни данные.** `suma(3)` — это всегда `6`, сколько ни вызывай.
   Такие функции называются **чистыми**.
3. **Не использует циклы `for` и `while`.** Повторение делается через **рекурсию**
   (функция вызывает саму себя) или через готовые функции `map`, `filter`, `reduce`.

Именно этого требует задание: «utilizând conceptele de bază a programării funcționale».

## 2. Минимум Python, чтобы читать код

| Что в коде | Что это значит |
| --- | --- |
| `def suma(n):` | Объявляем функцию с именем `suma`, которая принимает `n`. |
| `return x` | Функция отдаёт результат `x` и заканчивает работу. |
| `a if условие else b` | «Если условие верно — `a`, иначе — `b`». Короткий `if`. |
| `[1, 2, 3]` | Список. `[]` — пустой список. |
| `[1] + [2, 3]` | Склейка списков, получится `[1, 2, 3]`. Старые списки не меняются. |
| `range(1, 6)` | Числа `1, 2, 3, 4, 5` (последнее число **не** входит). |
| `lambda x: x * x` | Маленькая функция без имени: «дай `x` — верну `x * x`». |
| `map(f, список)` | Применить `f` к каждому элементу: `map(lambda x: x*x, [1,2,3])` → `1, 4, 9`. |
| `filter(f, список)` | Оставить только те элементы, где `f` вернула `True`. |
| `reduce(f, список, старт)` | «Свернуть» список в один результат, шаг за шагом (подробно ниже). |
| `raise ValueError("...")` | Остановить функцию с ошибкой и сообщением. |
| `match ... case ...` | «Сопоставление с образцом»: проверяем, на что похожи данные (подробно ниже). |

### Как работает `match` со списками

```python
match L:
    case []:              # если список пустой
        ...
    case [cap, *coada]:   # если в нём есть хотя бы один элемент
        ...
```

Во втором случае Python сам разрезает список:

- `cap` («голова») — **первый** элемент;
- `coada` («хвост») — **все остальные** элементы, тоже списком.

Пример: для `L = ['a', 'b', 'c']` получится `cap = 'a'`, `coada = ['b', 'c']`.

Это тот же приём, что `car`/`cdr` в Lisp или `(x:xs)` в Haskell — классика функционального
программирования.

### Как работает рекурсия

Рекурсия — это когда функция решает задачу, **вызывая саму себя для задачи поменьше**.
В каждой рекурсивной функции обязательно есть две части:

1. **Базовый случай** — самая простая задача, ответ на которую известен сразу
   (например, «сумма от 1 до 0 равна 0»). Здесь рекурсия **останавливается**.
2. **Шаг** — сводим задачу к меньшей (например, «сумма до `n` = `n` + сумма до `n-1`»).

Без базового случая функция вызывала бы себя бесконечно.

## 3. Файл `liste_finite.py` — построение конечных списков (2 балла)

### `verifica_natural(n)` — проверка N

Проверяет, что `n` — натуральное число (целое, 0 или больше). Если нет — ошибка
`ValueError`. Возвращает то же `n`, поэтому её удобно ставить прямо внутрь выражения.

Зачем отдельная проверка `isinstance(n, bool)`: в Python `True` считается числом `1`,
а `False` — числом `0`. Мы не хотим, чтобы `patrate(True)` молча сработало.

### `patrate(n)` — пункт **1.a**, квадраты чисел до N

```python
return list(map(lambda x: x * x, range(1, n + 1)))
```

Читаем изнутри наружу для `n = 4`:

1. `range(1, 5)` → числа `1, 2, 3, 4`
2. `map(lambda x: x * x, ...)` → к каждому применяем «возвести в квадрат» → `1, 4, 9, 16`
3. `list(...)` → собираем в список → `[1, 4, 9, 16]`

Цикла нет — `map` сама проходит по всем числам.

### `factorial(n)` — один факториал

Факториал: `4! = 1 · 2 · 3 · 4 = 24`. Записан как уравнение:

- `0! = 1` (базовый случай)
- `n! = n · (n − 1)!` (шаг)

```python
return 1 if n == 0 else n * factorial(n - 1)
```

Как считается `factorial(3)`:

```text
factorial(3) = 3 * factorial(2)
             = 3 * (2 * factorial(1))
             = 3 * (2 * (1 * factorial(0)))
             = 3 * (2 * (1 * 1))
             = 6
```

### `factoriale(n)` — пункт **1.b**, список факториалов до N

```python
return reduce(lambda acc, k: acc + [acc[-1] * k], range(2, n + 1), [1])
```

Идея: каждый следующий факториал = предыдущий × следующее число
(`4! = 3! · 4`). Поэтому не надо считать каждый факториал заново.

`reduce` работает как снежный ком: берёт стартовое значение `acc` («накопленное») и по
очереди «докатывает» к нему каждое число `k`. `acc[-1]` — последний элемент списка.

Как считается `factoriale(4)` (числа `k` = `2, 3, 4`, старт `[1]`):

| Шаг | `acc` до шага | `k` | `acc[-1] * k` | `acc` после шага |
| --- | --- | --- | --- | --- |
| старт | — | — | — | `[1]` |
| 1 | `[1]` | 2 | 1 · 2 = 2 | `[1, 2]` |
| 2 | `[1, 2]` | 3 | 2 · 3 = 6 | `[1, 2, 6]` |
| 3 | `[1, 2, 6]` | 4 | 6 · 4 = 24 | `[1, 2, 6, 24]` |

Результат: `[1, 2, 6, 24]` = `[1!, 2!, 3!, 4!]`.

Важно: `acc + [...]` создаёт **новый** список, старый не меняется — это и есть неизменяемость.

## 4. Файл `siruri.py` — функции вычисления последовательностей (3 балла)

На картинке из задания три формулы. Каждую записываем как **уравнение** «ответ для `n`
через ответ для `n − 1`» — отсюда и название лабораторной «ecuații».

### `produs(x, n)` — формула **F(x, n) = x · n**

Умножение — это повторное сложение: `3 · 4 = 3 + 3 + 3 + 3`.

- `F(x, 0) = 0` (базовый случай: ноль раз сложить — ноль)
- `F(x, n) = x + F(x, n − 1)` (шаг)

```text
produs(3, 4) = 3 + produs(3, 3)
             = 3 + 3 + produs(3, 2)
             = 3 + 3 + 3 + produs(3, 1)
             = 3 + 3 + 3 + 3 + produs(3, 0)
             = 3 + 3 + 3 + 3 + 0
             = 12
```

### `suma(n)` — формула **F(n) = Σ(i=1..n) i**

Сумма `1 + 2 + ... + n`.

- `F(0) = 0`
- `F(n) = n + F(n − 1)`

```text
suma(3) = 3 + suma(2)
        = 3 + 2 + suma(1)
        = 3 + 2 + 1 + suma(0)
        = 3 + 2 + 1 + 0
        = 6
```

### `suma_dubla(n)` — формула **F(n) = Σ(j=1..n) Σ(i=1..j) i**

Двойная сумма. Внутренняя сумма `Σ(i=1..j) i` — это просто `suma(j)`. Значит, нужно
сложить `suma(1) + suma(2) + ... + suma(n)`.

- `F(0) = 0`
- `F(n) = suma(n) + F(n − 1)`

```text
suma_dubla(3) = suma(3) + suma(2) + suma(1) + 0
              =    6    +    3    +    1    + 0
              = 10
```

### `sir(f, n)` — строим саму последовательность

Принимает **функцию** `f` и возвращает список `[f(1), f(2), ..., f(n)]`:

```text
sir(suma, 5)       → [1, 3, 6, 10, 15]
sir(suma_dubla, 5) → [1, 4, 10, 20, 35]
```

Функция, которая принимает другую функцию как аргумент, называется **функцией высшего
порядка**. Это одна из главных идей функционального программирования.

В `main.py` для первой формулы `x` фиксируется через лямбду:
`sir(lambda k: produs(3, k), n)` → `[3, 6, 9, ...]`.

## 5. Файл `operatii_liste.py` — функции для работы со списками (5 баллов)

Все четыре функции устроены одинаково: **разрезать список на голову и хвост →
сделать что-то с головой → рекурсивно обработать хвост → склеить**.

### `GetN(L, n)` — пункт **3.a**, n-й элемент списка

Нумерация с **1** (первый элемент — `GetN(L, 1)`).

Логика: если нужен 1-й элемент — это голова. Иначе нужен `(n−1)`-й элемент хвоста.

```python
case []:            raise IndexError(...)          # список кончился — такого элемента нет
case [cap, *coada]: return cap if n == 1 else GetN(coada, n - 1)
```

```text
GetN(['a', 'b', 'c'], 3)
  cap='a', n≠1 → GetN(['b', 'c'], 2)
  cap='b', n≠1 → GetN(['c'], 1)
  cap='c', n=1 → ответ 'c'
```

Если попросить `GetN(['a', 'b'], 5)`, список закончится раньше, сработает `case []`, и
будет ошибка `IndexError`. Ноль и отрицательные позиции тоже дают ошибку.

### `Set(L)` — пункт **3.b**, каждый атом один раз

Убирает повторы, сохраняя порядок первого появления.

Логика: голову оставляем, а **из хвоста выкидываем все её копии** (через `filter`),
потом то же самое делаем с тем, что осталось.

```python
case [cap, *coada]:
    return [cap] + Set(list(filter(lambda x: x != cap, coada)))
```

`filter(lambda x: x != cap, coada)` — «оставь в хвосте только то, что **не равно** голове».

```text
Set([3, 1, 3, 2, 1])
  cap=3, хвост [1, 3, 2, 1], выкидываем 3 → [1, 2, 1]
  [3] + Set([1, 2, 1])
         cap=1, хвост [2, 1], выкидываем 1 → [2]
         [1] + Set([2])
                cap=2, хвост [] → [2] + Set([]) = [2] + [] = [2]
  = [3] + [1] + [2]
  = [3, 1, 2]
```

### `OddEven(L)` — пункт **3.c**, меняем местами соседей

Меняет местами элементы на позициях **1↔2, 3↔4, 5↔6, ...** (нечётная позиция ↔ чётная).
Если элементов нечётное количество, последний остаётся на месте.

```python
case [impar, par, *rest]: return [par, impar] + OddEven(rest)   # есть хотя бы 2 элемента
case _:                   return list(L)                        # 0 или 1 элемент — менять нечего
```

`case _` значит «во всех остальных случаях».

```text
OddEven([1, 2, 3, 4, 5])
  impar=1, par=2 → [2, 1] + OddEven([3, 4, 5])
                   impar=3, par=4 → [4, 3] + OddEven([5])
                                    один элемент → [5]
  = [2, 1] + [4, 3] + [5]
  = [2, 1, 4, 3, 5]
```

### `FuncList(L1, L2, F)` — пункт **3.d**, соединить два списка по функции F

Берёт элементы с одинаковых позиций из двух списков и применяет к ним функцию `F`.
`F` передаётся аргументом — это может быть сложение, умножение, `max` или любая лямбда.

```python
case [a, *rest1], [b, *rest2]: return [F(a, b)] + FuncList(rest1, rest2, F)  # в обоих есть элементы
case _:                        return []                                     # один из списков кончился
```

```text
FuncList([1, 2, 3], [10, 20], сложение)
  a=1, b=10 → [11] + FuncList([2, 3], [20])
                     a=2, b=20 → [22] + FuncList([3], [])
                                        второй список пуст → []
  = [11, 22]
```

Как только **один** из списков заканчивается, работа заканчивается. Поэтому длина
результата равна длине более короткого списка.

Примеры из `main.py`:

| Вызов | Результат |
| --- | --- |
| `FuncList([1,2,3,4,5], [10,20,30], operator.add)` | `[11, 22, 33]` |
| `FuncList([1,2,3,4,5], [10,20,30], operator.mul)` | `[10, 40, 90]` |
| `FuncList([1,2,3,4,5], [10,20,30], max)` | `[10, 20, 30]` |
| `FuncList([1,2,3,4,5], [10,20,30], lambda a, b: b - a)` | `[9, 18, 27]` |

`operator.add` — это просто готовая функция «сложить два числа», то же что `lambda a, b: a + b`.

## 6. Файл `main.py` — демонстрация

1. `citeste_n` берёт N из командной строки (`sh run.sh 7`) или спрашивает с клавиатуры.
   Проверяет, что N — число от 1 до 500, иначе выводит сообщение и завершается.
2. `rapoarte(n)` вызывает все функции лабораторной и возвращает **список строк** с результатами.
3. `main` склеивает строки через перевод строки (`"\n".join(...)`) и печатает.

Почему N не больше 500: каждый рекурсивный вызов занимает место в памяти, и Python
по умолчанию разрешает примерно 1000 вложенных вызовов. Рекурсивные функции делают
около `N` вложенных вызовов, так что 500 — граница с запасом.

## 8. Вопросы на защите и короткие ответы

**Что такое функциональное программирование?**
Стиль, где программа строится из чистых функций: функция только принимает данные и
возвращает результат, ничего не меняя вокруг. Вместо циклов — рекурсия и функции
`map`/`filter`/`reduce`.

**Что такое чистая функция?**
Функция, у которой результат зависит только от аргументов и которая ничего не меняет
снаружи. Например, `OddEven` не трогает исходный список, а строит новый.

**Что такое рекурсия и зачем базовый случай?**
Функция вызывает саму себя для задачи поменьше. Базовый случай (`n == 0` или пустой список)
останавливает рекурсию, иначе она шла бы бесконечно.

**Что такое функция высшего порядка?**
Функция, которая принимает другую функцию как аргумент или возвращает её. У нас это
`FuncList` (принимает `F`), `sir` (принимает `f`), а также `map`, `filter`, `reduce`.

**Что такое лямбда?**
Короткая функция без имени, записанная прямо на месте: `lambda x: x * x`.

**Что делает `reduce`?**
Сворачивает последовательность в один результат, проходя по ней шаг за шагом и неся с собой
накопленное значение. В `factoriale` накопленное значение — список уже найденных факториалов.

**Почему нет циклов `for`?**
Цикл меняет переменную на каждом шаге (`i = i + 1`), а в функциональном стиле переменные
не меняются. Повторение делается рекурсией или `map`/`reduce`.

**Что такое «голова» и «хвост» списка?**
Голова — первый элемент, хвост — все остальные. `case [cap, *coada]` разрезает список
именно так. Почти все функции работы со списками в функциональном стиле — это «обработай
голову, рекурсивно обработай хвост».
