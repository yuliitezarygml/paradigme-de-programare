# Lucrare individuală — aplatizarea listelor

## Задание

De realizat sarcina în paradigma funcțională și în paradigma procedurală.

Scrie o funcție care primește o structură de liste/tablouri imbricate și
returnează o listă unidimensională, conținând aceleași elemente, păstrând
ordinea lor originală.

```text
Вход:  [2, [2, 3], 4, [4]]
Выход: [2, 2, 3, 4, 4]
```

Язык реализации: **Python 3.10 или новее**. Дополнительные библиотеки
устанавливать не нужно.

## Файлы

- `functional.py` — функция `flatten_functional`, функциональный подход.
- `procedural.py` — функция `flatten_procedural`, процедурный подход.
- `main.py` — запуск обеих функций на примере из задания.
- `test_flatten.py` — проверка результатов и сохранности исходных данных.

## Запуск

Из корня проекта:

```bash
python3 individul/main.py
```

Результат:

```text
Structura inițială: [2, [2, 3], 4, [4]]
Paradigma funcțională: [2, 2, 3, 4, 4]
Paradigma procedurală: [2, 2, 3, 4, 4]
```

Чтобы проверить другую структуру, измени переменную `data` в `main.py`.

## Как работает функциональное решение

В `flatten_functional` результат получается композицией преобразований:

1. `map` применяет лямбда-функцию к каждому элементу.
2. Если элемент — список или кортеж, функция рекурсивно разворачивает его.
   Обычный элемент превращается в список из одного элемента: `[item]`.
3. `chain.from_iterable` последовательно объединяет полученные списки.
4. `list` собирает элементы в итоговый список.

Явного цикла и изменяемого накопителя в функции нет. Функция не меняет
входные данные и не имеет внешних побочных эффектов: для одинаковых входных
данных она возвращает одинаковый результат. Python поддерживает несколько
парадигм; здесь используется функциональный стиль.

## Как работает процедурное решение

В `flatten_procedural` явно задаётся последовательность действий:

1. Создать пустой список `result`.
2. Обойти входную структуру циклом `for`.
3. Вложенный список или кортеж развернуть рекурсивным вызовом, затем
   добавить его элементы в `result` через `extend`.
4. Обычный элемент добавить через `append`.
5. Вернуть заполненный список.

Здесь результат накапливается пошагово: локальный список `result` изменяется
во время обхода. Исходная структура при этом остаётся прежней.

Рекурсия используется в обоих решениях. Отличие парадигм в этом примере —
в композиции преобразований у функционального варианта и явном управлении
циклом и изменяемым накопителем у процедурного.

## Поддерживаемые данные

Обе функции принимают списки и кортежи, в том числе вложенные друг в друга.
Пустые вложенные структуры не добавляют элементов в результат. Порядок,
повторяющиеся значения и типы обычных элементов сохраняются; например,
строка `"ab"` остаётся одним элементом.

## Проверка

Из корня проекта:

```bash
python3 -m unittest discover -s individul -p 'test_*.py' -v
```

Проверяются восемь наборов данных для каждой реализации: пример из задания,
пустой список, вложенные пустые списки, плоский список, несколько уровней
вложенности, нули и отрицательные числа, разные типы элементов и кортежи.
Также проверяется, что возвращается новый список и входные данные не меняются.
