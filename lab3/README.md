# Лабораторная 3 Rețeaua locală

Программа локального чата на **Python 3.10+ и Tkinter**. Сервер и клиент
открываются отдельно. Сторонние библиотеки не нужны.

## Запуск

В папке `lab3`:

```sh
sh run.sh
```

Откроется выбор: **панель сервера** или **клиент**. Можно открыть несколько клиентов.
Каждому участнику задайте своё имя.

Для отдельных терминалов удобнее:

```sh
sh run_server.sh
```

```sh
sh run_client.sh
```

1. В панели сервера нажмите **Запустить**. Обычный порт — `5050`.
2. В панели сервера создайте нужные комнаты. `General` создаётся при первом запуске.
3. В клиенте укажите имя, IP сервера и порт, затем нажмите **Подключиться**.
4. На одном компьютере используйте IP `127.0.0.1`.
5. На другом компьютере в той же локальной сети введите LAN IP компьютера с сервером.
   Его можно посмотреть в панели сервера или в настройках сети. Если система спросит,
   разрешите Python принимать подключения из локальной сети.
6. Выберите комнату в боковой панели клиента. Для общего чата выберите одну комнату.
   Новые комнаты появляются в списке автоматически; клиент их не создаёт.

Оба окна используют тёмную тему. Свои сообщения находятся справа, чужие — слева,
в отдельных пузырях. Нажатие на пузырь выбирает сообщение для ответа или копирования.

## Управление комнатами

В панели сервера доступны:

- **Создать комнату** — ввести название и нажать кнопку.
- **Закрыть комнату** — запретить новые сообщения и файлы, сохранив чтение истории.
- **Открыть комнату** — снова разрешить переписку.
- **Очистить историю** — удалить сообщения выбранной комнаты после подтверждения.
- **Удалить комнату** — удалить комнату вместе с её историей после подтверждения.

Удаление комнаты переводит её участников в выбор комнат. Все изменения сразу видны клиентам.

Сервер работает, пока открыта его панель и не нажата кнопка **Остановить**.
Закрытие клиента не останавливает отдельный сервер.

На Windows: `py server_app.py` и `py app.py`.
Параметры командной строки не нужны. Адрес и порт меняются в окнах программы.

## Что реализовано

| Пункт задания | Как проверить |
| --- | --- |
| a. Отправка и получение сообщений | Подключить двух клиентов, отправить текст. Enter — отправка, Shift+Enter — новая строка. |
| b. История | Переподключить клиента или перезапустить сервер. Старая переписка загрузится автоматически. Кнопка «Ранняя история» загружает предыдущие сообщения. |
| c. Reply | Нажать на сообщение, затем «Ответить». Ввести и отправить текст — появится цитата. |
| d. Файлы | «Прикрепить файл», затем у другого клиента выбрать сообщение с файлом и нажать «Скачать». Максимум 10 МБ. |
| e. Chat-room | Подключить три и более клиента к одному серверу и комнате: сообщения видны всем. |

## История и логи

- `data/rooms/<идентификатор>.json` — отдельный файл каждой комнаты: название,
  состояние (открыта/закрыта), счётчик и список сообщений.
- Старый `data/history.json`, если он есть, переносится по комнатам при первом запуске
  новой версии. Исходный файл остаётся как резервная копия и больше не обновляется.
- `data/files/` — переданные файлы. На сервере им присваиваются уникальные имена,
  а исходное имя сохраняется в JSON.
- Логи видны **в консоли** и в панели сервера. Файлы логов **не создаются**.

Пример сообщения внутри массива `messages` файла комнаты:

```json
{
  "id": 1,
  "room": "General",
  "sender": "Ion",
  "text": "Salut!",
  "timestamp": "2026-10-23T10:00:00+00:00",
  "reply": null,
  "file": null
}
```

## Где менять код

| Файл | Что делает |
| --- | --- |
| `run.py` | Запуск и выбор сервер/клиент. |
| `server_app.py` | Окно сервера: кнопки запуска/остановки, участники, логи. |
| `app.py` | Окно клиента: поля, кнопки, переписка. Размер окна задан в `geometry`. |
| `chat_view.py` | Пузыри сообщений: расположение справа/слева, время и цитаты. |
| `client.py` | Подключение клиента, отправка сообщений и файлов. |
| `server.py` | Приём подключений и рассылка сообщений участникам комнаты. |
| `history.py` | Чтение и запись JSON. |
| `protocol.py` | Передача JSON по TCP. `DEFAULT_PORT` — общий порт, `MAX_FILE_SIZE` — ограничение файла. |
| `test_chat.py` | Автоматические проверки без открытия окон. |
| `theme.py` | Цвета и шрифты обоих окон. Здесь проще всего менять оформление. |

В коде используются простые классы: `ChatServer`, `ChatClient`, `ChatHistory`.
Они хранят своё состояние и предоставляют методы для работы с ним — это инкапсуляция.
Классы окон наследуются от `tk.Tk`, а обработчик логов — от `logging.Handler`.

TCP передаёт поток байтов, поэтому `protocol.py` сначала отправляет четыре байта длины,
затем сам JSON. Файлы кодируются в Base64, чтобы их тоже можно было передать внутри JSON.
Сеть работает в потоках, чтобы окно не зависало; события приходят в окно через `Queue`.

## Проверка

```sh
python3 -m unittest -v test_chat
```

Тестам Tkinter не нужен. Они запускают настоящий TCP-сервер на свободном локальном
порту и проверяют сообщения, групповой чат, ответы, файлы и восстановление JSON-истории.
