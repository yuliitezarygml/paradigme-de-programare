## 3. 🧠 Архитектура ООП и жизненный цикл вычислений

Калькулятор построен на базе классических 4 принципов ООП:

```
                  ┌──────────────────────┐
                  │ <<interface>>        │
                  │   Operation          │
                  │ + getName(): String  │
                  └──────────▲───────────┘
                             │
            ┌────────────────┴────────────────┐
            │ implements                      │ implements
┌───────────────────────────────┐ ┌───────────────────────────────┐
│     BinaryOperation           │ │      UnaryOperation           │
│   (Абстрактный класс)         │ │   (Абстрактный класс)         │
│ + calculate(a, b): double     │ │ + calculate(a): double        │
└───────────────▲───────────────┘ └───────────────▲───────────────┘
                │ extends                         │ extends
     ┌──────────┴──────────┐            ┌─────────┴─────────┐
 ┌───────┐ ┌────────┐ ┌────────┐    ┌────────┐ ┌───────┐ ┌────────┐
 │Addition│ │Division│ │ Power  │... │SquareRt│ │ Sinus │ │Fact-ial│...
 └───────┘ └────────┘ └────────┘    └────────┘ └───────┘ └────────┘
```

### 1. Инкапсуляция (`Memory.java`, `Calculator.java`)
- Все внутренние переменные объявлены как `private`:
  - `private double memoryValue` в `Memory.java` (строка 6).
  - `private double firstNumber` в `Calculator.java` (строка 35).
  - `private BinaryOperation currentOperation` (строка 36).
  - `private boolean isNewInput` (строка 37).
- Внешний доступ возможен только через публичные контролируемые методы (`memory.store()`, `memory.recall()`, `getCurrentNumber()`).

### 2. Абстракция (`Operation.java`, `BinaryOperation.java`, `UnaryOperation.java`)
- Пользовательский интерфейс не знает внутренних формул. Он взаимодействует с абстрактным методом `calculate()`.
- Исключения объявляются в сигнатуре `throws Exception`, что позволяет безопасно обрабатывать любые математические ошибки.

### 3. Наследование (`extends`)
- Классы конкретных операций не дублируют общий код:
  - `class Addition extends BinaryOperation`
  - `class SquareRoot extends UnaryOperation`
- Окно калькулятора наследует библиотечный класс Java Swing: `class Calculator extends JFrame`.

### 4. Полиморфизм (`calculate`)
- В `Calculator.java` хранится одна переменная полиморфного типа:
  ```java
  private BinaryOperation currentOperation;
  ```
- При нажатии `+`, `-`, `*` или `/` в нее подставляется конкретный дочерний объект (`new Addition()`, `new Division()` и т.д.).
- При нажатии `=` вызывается один и тот же метод:
  ```java
  double result = currentOperation.calculate(firstNumber, secondNumber);
  ```
  Java во время выполнения сама вызывает нужный код нужного класса.

| **`MC`** | Memory Clear | Полностью очищает ячейку памяти | `Calculator.java` строки 316–318<br>`Memory.java` строки 12–15 | `memory.clear()` | Присваивает `memoryValue = 0.0` и `hasValue = false`. Индикатор памяти в левом верхнем углу очищается. |
| **`MR`** | Memory Recall | Извлекает число из памяти и выводит его на экран | `Calculator.java` строки 319–323<br>`Memory.java` строки 18–20 | `memory.recall()` | Если `memory.hasValue() == true`, считывает сохраненное число `recall()` и отображает его в поле ввода, включая `isNewInput = true`. |

### 4.4. Бинарные арифметические операции

Бинарные операции требуют двух чисел ($A$ и $B$) и нажатия клавиши **`=`**.  
Все классы наследуют `operations.BinaryOperation` и реализуют `calculate(double a, double b)`.

| Кнопка | Операция | Файл класса | Метод вычисления | Обработка граничных случаев и ошибок |
| :---: | :--- | :--- | :--- | :--- |
| **`+`** | Сложение | `src/operations/Addition.java`<br>(строки 1–17) | `return a + b;` | Корректно складывает положительные, отрицательные и дробные числа. |
| **`-`** | Вычитание | `src/operations/Subtraction.java`<br>(строки 1–17) | `return a - b;` | Вычитает второе число из первого. |
| **`*`** | Умножение | `src/operations/Multiplication.java`<br>(строки 1–17) | `return a * b;` | При умножении на 0 возвращает 0. Поддерживает дробную точность. |
| **`/`** | Деление | `src/operations/Division.java`<br>(строки 1–19) | `if (b == 0) throw Exception;`<br>`return a / b;` | **Защита от деления на 0:** если $b = 0$, выбрасывает `Exception("Împărțire la zero!")`. Калькулятор ловит ошибку и пишет `Eroare: Împărțire la zero!`. |
| **`x^y`** | Степень | `src/operations/Power.java`<br>(строки 1–17) | `return Math.pow(a, b);` | Возводит число $a$ в степень $b$. Поддерживает дробные и отрицательные степени. |
| **`mod`** | Остаток | `src/operations/Modulo.java`<br>(строки 1–17) | `if (b == 0) throw Exception;`<br>`return a % b;` | Вычисляет остаток от деления. Защищен от деления на 0. |
| **`=`** | Равно | `src/Calculator.java`<br>(строки 420–438) | `handleEquals()` | 1. Считывает второе число с экрана.<br>2. Вызывает `currentOperation.calculate(firstNumber, secondNumber)`.<br>3. Выводит результат на экран.<br>4. В строке истории пишет `A op B =`.<br>5. Сохраняет результат в `firstNumber` для возможности продолжать цепочку вычислений. |

### 4.5. Базовые унарные математические функции

Унарные операции выполняются **мгновенно над числом на экране**, без ожидания нажатия клавиши `=`.  
Все классы наследуют `operations.UnaryOperation` и реализуют `calculate(double a)`.

| Кнопка | Функция | Файл класса | Формула | Обработка ошибок |
| :---: | :--- | :--- | :--- | :--- |
| **`√x`** | Квадратный корень | `src/operations/SquareRoot.java`<br>(строки 1–19) | $\sqrt{a}$ (`Math.sqrt(a)`) | Если $a < 0$, выбрасывает исключение: `Radical din număr negativ!`. |
| **`x²`** | Квадрат числа | `src/operations/Square.java`<br>(строки 1–17) | $a^2$ (`a * a`) | Быстрое умножение числа самого на себя. |
| **`1/x`** | Обратное число | `src/operations/Reciprocal.java`<br>(строки 1–19) | $\frac{1}{a}$ (`1.0 / a`) | Если $a = 0$, выбрасывает исключение: `Împărțire la zero!`. |
| **`%`** | Процент | `src/operations/Percent.java`<br>(строки 1–17) | $\frac{a}{100}$ (`a / 100.0`) | Переводит число в сотые доли (например, $25 \rightarrow 0.25$). |
| **`\|x\|`** | Модуль числа | `src/operations/AbsOperation.java`<br>(строки 1–17) | $\|a\|$ (`Math.abs(a)`) | Отбрасывает знак минус у отрицательного числа. |
| **`n!`** | Факториал | `src/operations/Factorial.java`<br>(строки 1–27) | $1 \cdot 2 \cdot \dots \cdot n$ | 1. Проверяет, что число целое и неотрицательное (`a < 0 \|\| a != Math.floor(a)`). Иначе: `Factorialul cere întreg pozitiv!`.<br>2. Защита от переполнения: при $a > 170$ выдает ошибку `Număr prea mare!`. |

### 4.6. Тригонометрия и переключатель углов

Классы тригонометрии расположены в `src/operations/` (`Sinus.java`, `Cosinus.java`, `Tangens.java`).  
Они поддерживают как градусы (**DEG**), так и радианы (**RAD**).

| Кнопка | Название | Файл класса | Математика | Особенности реализации |
| :---: | :--- | :--- | :--- | :--- |
| **`DEG / RAD`** | Переключатель единиц измерения углов | `Calculator.java`<br>строки 68–75 | Инвертирует флаг `isRadians = !isRadians` | Кнопка видна в научном режиме. По умолчанию активен режим **DEG** (градусы). При клике текст меняется на **RAD**, а тригонометрические функции перестают конвертировать входные данные. |

### 4.9. Режимы калькулятора и системы счисления

Переключение между режимами выполняется в выпадающем списке `modeBox` (`changeMode()` строки 192–216):

1. **`Standard` (Стандартный):**
   - Компактный размер окна ($360 \times 560$ px).
   - Базовая сетка кнопок $6 \times 4$: `+`, `-`, `*`, `/`, `√x`, `x²`, `1/x`, `%`, память.
2. **`Științific` (Научный):**
   - Расширенный размер окна ($440 \times 640$ px).
   - Сетка кнопок $7 \times 5$: появляются тригонометрия, логарифмы, факториал, $x^y$, степени, модуль, константы $\pi$ и $e$.
   - Включается кнопка переключения единиц измерения **DEG / RAD**.
3. **`Programator (Baze)` (Режим программиста):**
   - Размер окна ($400 \times 640$ px).
   - В верхней части окна активируется панель систем счисления (`programmerPanel` строки 111–132).
   - При любом вводе числа или результате вычислений метод `updateBases()` (строки 529–538) вызывает статические методы класса `BaseConverter.java`:
     - **`HEX`:** `BaseConverter.toHex(val)` — 16-ричный вид (в верхнем регистре).
     - **`DEC`:** Десятичное целое число `val`.
     - **`OCT`:** `BaseConverter.toOct(val)` — 8-ричный вид.
     - **`BIN`:** `BaseConverter.toBin(val)` — двоичный вид (биты `0` и `1`).
   - На клавиатуре появляются шестнадцатеричные кнопки `A`, `B`, `C`, `D`, `E`, `F`.

### 4.10. Горячие клавиши физической клавиатуры

Калькулятор слушает нажатия реальных клавиш через `KeyListener` (`Calculator.java` строки 154–171 и метод `handleKeyInput` строки 541–558):
- **Цифры `0`–`9`:** прямой ввод цифр.
- **Точка `.` или запятая `,`:** ввод десятичной точки.
- **Знаки `+`, `-`, `*`, `/`:** выбор соответствующей бинарной операции.
- **Клавиша `Enter` или `=`:** вычисление результата (`handleEquals()`).
- **Клавиша `Backspace` (Стереть):** удаление последней цифры (`handleBackspace()`).
- **Клавиша `Escape` (Esc):** полный сброс калькулятора (`handleClearAll()`).

## 5. 🔄 Пошаговые сценарии работы программы

### Сценарий 1: Вычисление $15 + 7 = 22$
1. Пользователь нажимает кнопки `1` и `5`:
   - Срабатывает `handleDigit("1")`, затем `handleDigit("5")`.
   - На экране `displayField` отображается `"15"`, флаг `isNewInput` равен `false`.
2. Пользователь нажимает `+`:
   - Вызывается `setBinaryOperation(new Addition(), "+")`.
   - Переменная `firstNumber` запоминает `15.0`.
   - В поле `currentOperation` записывается экземпляр класса `Addition`.
   - В строке истории `historyLabel` появляется надпись `"15 +"`.
   - Флаг `isNewInput` становится `true`.
3. Пользователь нажимает `7`:
   - Так как `isNewInput == true`, старая надпись заменяется на `"7"`.
   - `isNewInput` переводится в `false`.
4. Пользователь нажимает `=`:
   - Вызывается `handleEquals()`.
   - Считывается второе число `secondNumber = 7.0`.
   - Вызывается полиморфный метод `currentOperation.calculate(15.0, 7.0)`.
   - В классе `Addition.java` выполняется `15.0 + 7.0`, возвращается `22.0`.
   - На экран выводится `"22"`, а в историю: `"15 + 7 ="`.
   - Переменная `firstNumber` обновляется на `22.0`, позволяя нажать следующий знак (например, `* 2`).

### Сценарий 2: Деление на ноль ($10 / 0$)
1. Пользователь вводит `10`, нажимает `/`, вводит `0` и нажимает `=`.
2. `handleEquals()` вызывает `currentOperation.calculate(10.0, 0.0)`.
3. В классе `Division.java` срабатывает условие:
   ```java
   if (b == 0) throw new Exception("Împărțire la zero!");
   ```
4. В блоке `catch (Exception ex)` перехватывается исключение, и экран выводит дружественное сообщение:  
   `Eroare: Împărțire la zero!`.
5. Программа не падает аварийно, а ожидает нажатия кнопки `C` для продолжения работы.

## 6. 🎓 Шпаргалка к защите перед преподавателем

**Вопрос 1: Где в коде реализован полиморфизм?**  
*Ответ:* В файле `Calculator.java`, строка 36 объявлена переменная абстрактного базового типа:  
`private BinaryOperation currentOperation;`.  
В зависимости от нажатой кнопки (`+`, `-`, `*`, `/`) мы присваиваем туда разные объекты (`new Addition()`, `new Division()` и т.д.). В строке 424 мы просто пишем `currentOperation.calculate(firstNumber, secondNumber);`. JVM сама во время выполнения выбирает нужный метод нужного класса.

**Вопрос 2: Как разделены графический интерфейс (GUI) и бизнес-логика?**  
*Ответ:* Окно `Calculator.java` отвечает только за отображение кнопок и перехват кликов мыши. Сама математика вынесена в отдельные независимые классы в пакете `operations/`. Их можно тестировать без создания окна, что и демонстрирует тестовый класс `TestCalculator.java`.

**Вопрос 3: Как инкапсулирована память калькулятора?**  
*Ответ:* Класс `Memory.java` хранит значение `memoryValue` в закрытом поле `private`. Изменить или прочитать его можно только через методы `store()`, `recall()`, `add()`, `subtract()`, `clear()`. Это защищает данные от несанкционированного изменения.

**Вопрос 4: Как обрабатываются тригонометрические функции в градусах и радианах?**  
*Ответ:* В стандартной Java библиотека `Math.sin()` принимает только радианы. В классах `Sinus`, `Cosinus`, `Tangens` в конструктор передается булев флаг `isRadians`. Если флаг `false`, угол предварительно конвертируется вызовом `Math.toRadians(a)`.
